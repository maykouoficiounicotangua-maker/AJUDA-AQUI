# Produto

**AJUDA AQUI — Pessoas ajudando pessoas.**

## Conceito
Um único tipo de usuário. Em cada fluxo o comportamento define o papel: quem publica um pedido é *solicitante*; quem demonstra interesse é *ajudante*.

## Fluxo principal
Pedido (wizard 7 etapas) → publicado/aberto → ajudante vê em Explorar (com matching) → "TENHO INTERESSE" (proposta) → solicitante recebe notificação → vê perfil → aceita (transação atômica: proposta aceita, demais rejeitadas, pedido ASSIGNED, conversa criada, notificações) → ambos confirmam (IN_PROGRESS) → ajuda realizada → ambos confirmam conclusão (COMPLETED) ou "TIVE UM PROBLEMA" (DISPUTED) → avaliações → reputação.

## Tipos de ajuda
FREE, PAID (valor em centavos), EXCHANGE (descrição da troca). Sem pagamentos na plataforma.

## Fora do escopo do MVP
Pagamentos, carteira, anúncios, assinatura, IA, mapa obrigatório, ranking, seguidores, feed.

## Roadmap
V2 mapa/push avançado/matching avançado · V3 pagamentos/verificação de identidade · V4 IA.
